{# ------------------------------------------------------------------ ai #}

YOUR AI ASSISTANT

AI can turn notes you already have (Word, PowerPoint, PDF, text) into Studiamo notes with code boxes, file trees and live diagrams. There are two ways to connect it, and you can use both. Either way the result is a draft: you check it, and an admin reviews it before students see it.

A · API KEY · INSIDE STUDIAMO

You paste an API key here once: Claude (the default), Gemini or OpenAI, or several and switch whenever you like. Then the note editor's Import button sends your file to that AI and puts the converted note in the editor.

  • Fastest: one click, nothing to install.
  • Works from any computer you log in on.
  • You pay the AI company for what you use (your key, your account); Gemini has a free tier. The file you import is sent to them.
  • A ChatGPT, Gemini or Claude subscription is not an API key: keys come from the developer consoles linked below.

Best for: importing notes one by one while you write in the Studio.

B · MCP · FROM YOUR AI APP

You connect the AI app you already use to Studiamo with a Studiamo key. MCP is an open standard, so the model does not matter: Claude Code, Claude Desktop, Gemini CLI, and editors like VS Code or Cursor all work. Then you talk to it there: “convert these notes and save them in Week 2”.

  • Uses your AI app's own subscription: no API key needed.
  • It can work on many notes, reorganise topics, and fix notes you already wrote.
  • Your app must stay connected; it works where the app is installed.

Best for: converting a whole course, or longer work with an assistant.

2 · CONNECT YOUR APP

Server address (MCP, HTTP):

Claude Code (terminal):

claude mcp add --transport http studiamo {{ mcp_url }} --header "Authorization: Bearer {{ key }}"

Gemini CLI (add to ~/.gemini/settings.json):

{
  "mcpServers": {
    "studiamo": {
      "httpUrl": "{{ mcp_url }}",
      "headers": { "Authorization": "Bearer {{ key }}" }
    }
  }
}

Claude Desktop and other apps (their MCP config file, through mcp-remote, needs Node.js):

{
  "mcpServers": {
    "studiamo": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ mcp_url }}",
               "--header", "Authorization:Bearer {{ key }}"]
    }
  }
}

ChatGPT and other web apps run on their company's servers, so they can only connect once Studiamo is online at a public address, and they expect a “Sign in with Studiamo” login rather than a pasted key. Until then, use one of the apps above.

3 · ASK IT

Paste or attach your old notes and say, for example: “Convert these notes into a Studiamo note in my course FP101, topic Week 2.” Apps that show MCP prompts also offer Convert my notes to Studiamo. Then open the draft in the Studio, check it, and submit it for review.
